# ДТС — UNICON.UZ

Интерактивный сайт о Национальной службе доверенной третьей стороны Узбекистана. React + Vite, три языка: русский, узбекский и английский.

Сайт: https://unicondts.netlify.app

## Возможности

- Раскрывающиеся схемы местного и международного взаимодействия, TEHAT.UZ и единой базы цифровых данных.
- Географическая карта партнёров с масштабированием.
- Анимированные связи, значки, пояснения и справка о RFC 3029.
- Редактор данных стран: изменения сохраняются в текущем браузере.

## Запуск

Установите Node.js 22 или новее и pnpm. В папке проекта выполните:

```sh
pnpm install
pnpm dev
```

Сборка для публикации:

```sh
pnpm build
```

Результат сборки находится в `dist`. Эта папка загружается на Netlify.

## Где вносить изменения

- `src/Atlas.jsx` — схемы, навигация и карта.
- `src/content.js` — исходные данные и этапы сотрудничества.
- `src/atlasTranslations.js` и другие словари в `src` — переводы.
- `src/atlas.css`, `src/light.css` — оформление и анимации.
- `public` — логотип и географические данные.

Этапы сотрудничества внесены по сведениям заказчика. Soliq.uz интегрирован; сотрудничество с Центром управления проектами цифрового правительства и интеграция с железной дорогой планируются. Схемы поясняют архитектуру и не являются технической спецификацией действующих подключений.
