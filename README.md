# ДТС — архитектура доверия

React-приложение с интерактивной схемой, пошаговым показом обмена, картой стран и локальным редактором.

## Запуск

Установите Node.js 22 и pnpm. Выполните `pnpm install`, затем `pnpm dev`. Для сборки: `pnpm build`.

## Изменения

- `src/content.js`: узлы схемы, объяснения, этапы и исходные страны.
- `src/main.jsx`: интерфейс и интерактивное поведение.
- `src/style.css`: оформление и анимации.

Этапы сотрудничества внесены из предоставленных сведений: Россия, Казахстан — обновление от 10.09.2026; SHECA — от 06.10.2026; Беларусь, Кыргызстан, Азербайджан — от 12.10.2026. В карточках указаны даты, известный этап и следующий шаг. Названия партнёров и точные сроки внесены только при наличии данных. Общие объяснения основаны на предоставленной схеме; они не подтверждают конкретные юридические соглашения или технические подключения.

Редактор сохраняет данные только в браузере. Экспорт JSON позволяет передать правки для внесения в общую опубликованную версию. Поддерживается импорт экспортированного JSON. Позиции стран на карте схематические, редактируются в процентах. Оригинальный логотип UNICON.UZ взят с официального сайта unicon.uz и находится в public/unicon-logo.svg.


## Языки
Переключатель UZ / RU / EN переводит интерфейс, схему, этапы и исходные карточки стран. Выбор сохраняется в браузере. Переводы хранятся в src/translations.js. Тексты, добавленные пользователем, сохраняются в исходном виде; для них можно добавить перевод в словарь.



## IUT: новая раскрывающаяся архитектура
Главный интерфейс: src/Atlas.jsx, оформление: src/atlas.css, новые переводы: src/atlasTranslations.js. Старые компоненты сохранены как исходные материалы.
Четыре направления: местные организации, зарубежные страны, база данных, TEHAT.UZ. Роуминг доступен из главной схемы и местных интеграций. Каждая схема поддерживает последовательное раскрытие, паузу, ручные шаги и обзор всех узлов.
Границы карты: Natural Earth, подготовленный geo-countries (https://github.com/datasets/geo-countries), public/world-countries.geojson. Геометрия упрощена для быстрого отображения; маршруты схематичны.
Партнёр Кыргызстана обновлён на «Тундук». 27 участников НИЦ, Didox и проведённая интеграция железной дороги указаны по предоставленным пользователем сведениям; полный перечень НИЦ не предоставлен. Неизвестные протоколы и партнёры базы не выдуманы.
Редактор сохраняет данные стран локально (iut-atlas-countries) и экспортирует JSON. Публикация общих изменений требует обновления исходных данных и загрузки сайта.

Уточнение пользователя: интеграция проведена с Soliq.uz; Temir yo‘l планируется. Прежнее указание проведённой интеграции железной дороги ошибочно.
